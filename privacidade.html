Política de Privacidade

Atualizada em 17 de setembro de 2026.

Escopo

O Nexa Clips App é uma ferramenta de uso interno: publica vídeos do Nexa Clips nas contas do próprio Nexa Clips no YouTube, Instagram e TikTok, mediante autorização (OAuth) do titular dessas contas. Não coleta dados de outras pessoas.

Dados acessados

  • Permissão para publicar vídeos nas contas do projeto e ler dados básicos dessas contas.
  • Métricas das publicações feitas pela ferramenta (por exemplo, visualizações), usadas apenas para organizar o conteúdo do próprio projeto.

Uso e guarda

  • As autorizações ficam armazenadas localmente, no equipamento da equipe, e servem só para as funções acima.
  • Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.
  • O acesso pode ser revogado a qualquer momento nas configurações de cada plataforma (Google: myaccount.google.com/permissions); as autorizações guardadas são então descartadas.

Google

O uso de dados obtidos por APIs do Google segue a Google API Services User Data Policy, incluindo os requisitos de Uso Limitado.

Conteúdo de terceiros e contato
